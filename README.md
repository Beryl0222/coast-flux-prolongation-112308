# 潮间带 C 网格通量细化与压力修正

交错水动力网格的粗细边面交换资料。 仓库记录均为本地合成资料，不依赖外部数据服务。

## 数据约定

faces 每行是面号、起点单元、终点单元、粗边号、有效面积、预测的面积积分通量。正值从起点流往终点，单元源以流出减流入口径给定。外侧单元和内部面的粗边号分别用 null 表示。粗边以向域外为正，拼接面按同一编号和各自朝向引用。

cells 是单元号和面积积分后的净源。tide 中未出现的面干燥，粗边表的局部版本由 tide.coarse 给出。二次距离按面通量差的平方除有效面积计。

cotangent 是细面通量输出的种子。数值容限 1e-8，同一示例可将面和单元拆成任意多个交换片。

## 读取与核对

在 Python 3.11 环境执行 `python -m pip install -r requirements.txt` 安装数值依赖。
`python -m unittest discover -s tests -v` 读取 `data/exchange.json` 并核对资料结构与关键输入关系。
